日本語

Status Cat(以下「本拡張機能」)は、見ているページの HTTP ステータスを、ページの下のドット絵の猫たちとツールバーのバッジで知らせる Chrome 拡張機能です。このページでは、本拡張機能が扱うデータと、その行き先を説明します。

記録するデータ

各タブのステータスを表示するため、本拡張機能はタブごとに次のものを記録します。

  • 画面に出ているページ、そのタブで前に開いた最大 5 ページ、読み込み中のページ(サイトが裏で先読みするページを含む)
  • それぞれについて、アドレス(URL)、HTTP ステータスコード、ステータスの行、リダイレクト先のアドレス、ネットワークエラー名だけ

ページの中身、リクエストやレスポンスのヘッダー、フォームへの入力、Cookie、パスワードは読みません。

これらの記録は、端末のメモリ上にある chrome.storage.session に置かれます。タブを閉じるとそのタブの記録が消え、ブラウザを閉じるとすべて消えます。

設定は、端末の chrome.storage.local に保存します。猫を表示するか、猫の数と顔ぶれ、大きさ、猫を出さないサイト、バッジを出すページ、写真の設定です。

端末の外に出るもの

本拡張機能はサーバーを持たず、開発者を含むだれにも何も送りません。アクセス解析、広告、トラッキングもありません。

通信するのは、「http.cat の写真を表示する」をオンにしたとき(最初はオフ)の、http.cat からの写真の読み込みだけです。写真のアドレスに含まれるのはステータスコードだけです(例: https://http.cat/404.jpg)。ほかの Web ページの画像と同じく、このとき http.cat にはあなたの IP アドレスが届きます。また、ブラウザの既定の設定では、見ているページのオリジン(例: https://example.com)も Referer ヘッダーで届きます。そのリクエストの扱いは、http.cat 自身のポリシーによります。

共有と販売

本拡張機能は、データを販売、共有、譲渡しません。記録は、ページのステータスを表示するためだけに使います。

本拡張機能が受け取る情報の扱いは、Chrome ウェブストアのユーザーデータに関するポリシー(Limited Use の要件を含む)に従います。

見ている Web サイトについて

本拡張機能は、猫を描くために、猫の画像とスクリプトを Web ページから読める形にしています。そのため、Web サイトの側から本拡張機能が入っていることがわかります。Web サイトが本拡張機能の記録や設定を読むことはできません。

権限の使い道

  • webRequest: 各タブで開いたページ(メインフレーム)の、ステータスコード、ステータスの行、リダイレクト、エラー名を読みます。ヘッダーや中身は読まず、通信を止めたり書き換えたりもしません。
  • storage: 上に書いた記録と設定を保存します。
  • すべてのサイトへのアクセス: どのページの下にも猫を出し、どのサイトのステータスも読むために使います。

データの削除

記録は、タブやブラウザを閉じると消えます。本拡張機能を Chrome から削除すると、設定を含めてすべて消えます。

English

Status Cat ("the extension") is a Chrome extension that shows the HTTP status of the page you are on, with pixel cats at the bottom of the page and a badge on the toolbar icon. This policy explains what data it handles and where that data goes.

What Status Cat records

To show each tab's status, the extension records the following for every tab:

  • the page on screen, up to 5 earlier pages in that tab, and page loads still in progress (including pages a site prefetches in the background)
  • for each of these, only the address (URL), the HTTP status code, the status line, the addresses of any redirects and the network error name

It does not read page content, request or response headers, form data, cookies or passwords.

These records are kept in chrome.storage.session, which lives in memory on your device. A tab's records are removed when the tab closes, and all of them are cleared when the browser closes.

Your settings are kept in chrome.storage.local on your device: whether cats are shown, how many and which cats, their size, the sites where cats are hidden, the badge scope and the photo options.

What leaves your device

The extension has no server. It sends nothing to the developer or to anyone else, and it contains no analytics, advertising or tracking.

The only network requests it makes are for photos from http.cat, and only if you turn on "Show http.cat photos", which is off by default. The photo's address contains only the status code, for example https://http.cat/404.jpg. As with any image on a web page, http.cat receives your IP address with the request. By your browser's default settings it also receives the origin of the page you are on (for example https://example.com) in the Referer header. http.cat's own policies govern what it does with that request.

Sharing and sale

The extension does not sell, share or transfer your data. It uses the records only to show the status of your pages.

The use of information received by the extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Websites you visit

The extension makes its cat images and scripts available to web pages so that the cats can be drawn. A website can therefore detect that Status Cat is installed. Websites cannot read the extension's records or settings.

How each permission is used

  • webRequest: reads the status code, status line, redirects and error name of the pages (main frames) opened in each tab. It does not read headers or content, and it never blocks or changes requests.
  • storage: keeps the records and settings described above.
  • Access to all sites: lets the cats appear at the bottom of any page and lets the extension read the status of any site.

Deleting your data

The records disappear when you close the tab or the browser. Removing the extension from Chrome deletes everything, settings included.

Changes to this policy

When this policy changes, this page is updated along with the date at the top.
