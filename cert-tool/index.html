Read the certificate, not the base64.

Cert Tool puts a badge on every certificate and CSR on a page, with its name and days left. Click one for the subject, issuer, SANs and extensions.

Add to Chrome Try the popup without installing

Free. Runs entirely in your browser, with no account and no tracking.

Check certificates where you find them

Runbooks, pull requests, tickets and CI logs. Cert Tool reads a page only when you ask it to, never in the background.

  • docs.example.com64d leftValid
  • api.example.net12d leftUnder 30 days left
  • legacy.example.orgexpiredExpired or not yet valid

Scan the whole page

Open Cert Tool and click Scan this page on the Inspector tab. Every certificate and CSR gets a badge, colored by how long it has left. A pasted chain gets one badge that lists every certificate in it.

  • Copy⌘C
  • Print…⌘P
  • Inspect certificate with Cert Tool

Or only what you selected

Select a PEM block, right-click it, and choose Inspect certificate with Cert Tool. This works in code viewers and form fields too.

Private keys, cut-off blocks and text the page hides are skipped. Browser pages, such as chrome:// pages and the Chrome Web Store, can’t be scanned.

Five more tools in the popup

Paste a certificate, CSR or key, read the result, then copy it or save it to a file.

Check a server certificate before you deploy it

  • 30 checks for expiry, hostname coverage, key strength, weak signatures and more
  • CA/Browser Forum TLS Baseline Requirements, including the 200, 100 and 47-day validity limits
  • Public CA and Private CA profiles, picked from the certificate’s policies
  • Every finding cites the rule it comes from

Decode a certificate, chain or CSR

  • Subject, issuer, validity, key, signature and serial number
  • SANs, key usage, CRL and OCSP URLs, policies, SCTs and other extensions, decoded
  • Paste a full chain and switch between the leaf and intermediates

Generate a key pair

  • RSA 2048/4096, ECDSA P-256/P-384/P-521 and Ed25519
  • Made with your browser’s Web Crypto API
  • Saved as PKCS#8 and SPKI PEM files

Build a certificate signing request

  • Subject fields and SANs: DNS names, IP addresses, emails and URIs
  • Signed with your own private key

Get the public key

  • From a private key, a certificate or a CSR
  • The input type and algorithm are detected for you

Nothing leaves your browser

Cert Tool has no server and makes no network requests. It doesn’t store what you paste or what it reads from a page. Results are gone when you close the popup or reload the page.
