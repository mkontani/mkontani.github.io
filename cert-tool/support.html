Cert Tool — Support

Inspect, lint and generate X.509 certificates and keys — 100% in your browser.

Using Cert Tool

  • Install Cert Tool from the Chrome Web Store.
  • Click the toolbar icon to open the popup. It opens on the Inspector tab; the other tabs are Gen KeyPair, Gen CSR, Derive PubKey and Lint.
  • To see the certificate chain of the site you’re on, click Show this site’s certificate on the Inspector tab.
  • To check the certificates on a page, click Scan this page on the Inspector tab. Hover over or click a badge for details.
  • To check one block, select it, right-click, and choose Inspect certificate with Cert Tool.

Common questions

Cert Tool says it can’t read the page

Chrome doesn’t let extensions read its own pages, such as chrome:// pages, the Chrome Web Store, and other extensions’ pages. Show this site’s certificate also needs a page loaded over HTTPS. Copy the certificate into the Inspector tab instead.

Cert Tool says another extension has added its own frame to the page

Some extensions add their own frame to pages, such as the bar Vimium shows once you use it, and Chrome then keeps other extensions’ debuggers off the tab. In that case Show this site’s certificate reads the certificate over Cert Tool’s own connection to the site instead, and the summary says so. A few sites refuse that request. On those, reload the page and click the button again before using the other extension, or turn that extension off for the site.

Why does Chrome say Cert Tool “started debugging this browser”?

Show this site’s certificate reads the certificate through Chrome’s debugger, the only way Chrome lets extensions read it. The bar shows while Cert Tool reads it, and Cert Tool detaches right after. This is also why Chrome asks you to approve “Access the page debugger backend” when you install or update Cert Tool.

A certificate on the page has no badge

Cert Tool skips private keys, blocks that are cut off (no END line), and text the page hides. If the certificate is in a collapsed section, expand it and scan again.

Does Cert Tool check whether a certificate is trusted?

Not by itself. Cert Tool shows what a certificate says. It doesn’t verify signatures, build chains to a trusted root, or check revocation. The exception is Show this site’s certificate: it shows the chain Chrome verified for the site, and whether Chrome accepted it.

Are my keys sent anywhere?

No. Cert Tool sends nothing to its developer or anyone else, and stores nothing. The only request it causes is a HEAD request without cookies to the site you’re on, when you click Show this site’s certificate. See the Privacy Policy.
