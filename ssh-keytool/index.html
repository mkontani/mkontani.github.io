Hardware security keys

FIDO keys, without the man page.

A FIDO key lives on a YubiKey or similar, so no browser can create it for you. SSH Keytool writes the exact commands instead — and reads the result back.

  • Pick the algorithm and the resident, PIN and touch options; every user-entered value is shell-quoted.
  • Get the server side too: an authorized_keys line with the right options, and an optional PubkeyAuthOptions line.
  • On macOS, the built-in ssh-keygen has no FIDO support — the builder tells you to use Homebrew’s OpenSSH.

1. Generate (run on your machine)

$ ssh-keygen -t ed25519-sk -O application=ssh:work -O verify-required -C alice@laptop -f ~/.ssh/id_ed25519_sk

2. Server: ~/.ssh/authorized_keys

verify-required <contents of ~/.ssh/id_ed25519_sk.pub>

3. Optional: sshd_config

PubkeyAuthOptions touch-required verify-required

Privacy

Your private keys never leave the popup.

SSH Keytool makes no network requests and stores nothing. Keys are generated and parsed in memory on your device, and everything is gone when you close the popup.
