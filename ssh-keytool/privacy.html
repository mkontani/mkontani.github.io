SSH Keytool — Privacy Policy

Last updated: 2026-11-03

SSH Keytool is a Chrome extension. It generates SSH key pairs, derives public keys, inspects SSH certificates and FIDO keys, converts private keys between formats, and builds ssh-keygen commands for FIDO security keys. Everything runs inside your browser. SSH Keytool has no server, no account, and no analytics, and it makes no network requests.

What SSH Keytool handles

  • Text you enter in the popup, such as private keys, public keys, SSH certificates, passphrases, and the options and comments you type into the FIDO command builder.
  • Keys that SSH Keytool generates or converts for you.

SSH Keytool does not read web pages, your files, or your clipboard.

How it is used

SSH Keytool uses this data only to show you results: new key pairs, public keys, converted keys, certificate and key details, and commands. The data is processed in memory on your device.

Storage

SSH Keytool does not store any of this data. It uses no extension storage, cookies, or local storage.

  • Everything in the popup is gone when the popup closes.
  • Text is copied to the clipboard only when you click a Copy button.

Sharing

No data leaves your device. SSH Keytool does not sell, transfer, or share user data with anyone. It does not use data for advertising or to determine creditworthiness.

The use of information received by SSH Keytool adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Permissions

  • clipboardWrite: copies a key, command, or snippet to the clipboard when you click a Copy button.

Web version

The same app is also published as a web page at mkontani.github.io/ssh-keytool-extension. The page is hosted on GitHub Pages, which may log standard request information (such as your IP address) when it serves the page; see the GitHub Privacy Statement. Once loaded, the page works the same way as the extension: it makes no further network requests and stores nothing.

Children's privacy

SSH Keytool does not collect data from anyone, including children.
