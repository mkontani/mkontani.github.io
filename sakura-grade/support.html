サクラ診断 — サポート

Amazon レビューの評価分布を端末内で診断する Chrome 拡張。

使い方

  • 拡張を Chrome ウェブストアからインストールし、Amazon.co.jp の商品ページを開きます。
  • 商品の評価(★)の近くに A〜F のバッジが表示されます。
  • バッジをクリックするとパネルが開き、評価分布のグラフと判定理由が見られます。
  • 対応端末では、パネル内に端末内AIによる文面解析（サクラ度・不自然な点・低評価の要点）も表示されます。

端末内AIについて

  • AI解析は Chrome の組み込みAI（Prompt API / Gemini Nano）に対応した端末でのみ動作します。
  • モデル（約2GB）が未ダウンロードの場合は、パネルの準備ボタンからダウンロードを開始できます。
  • AIに対応していない端末でも、評価分布による A〜F 診断は問題なく利用できます。

バッジが表示されないとき

  • 商品ページ（/dp/ を含むURL）であることを確認してください。レビューが無い商品では表示されません。
  • ページを再読み込みしてみてください。Amazon のページ構成変更により一時的に表示されない場合があります。
  • 拡張が有効になっているか、chrome://extensions で確認してください。

プライバシー

すべての処理はあなたの端末内で完結します。レビュー内容も診断結果も外部に送信されません。詳しくはプライバシーポリシーをご覧ください。
