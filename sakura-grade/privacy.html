サクラ診断 — プライバシーポリシー

最終更新: 2026-11-21

「サクラ診断」は、Amazon.co.jp の商品レビューの評価分布を診断するブラウザ拡張（Chrome 版・Safari 版）です。プライバシー保護を設計の中心に据えています。

データを一切収集しません

サクラ診断は、いかなる個人情報・利用データも収集・保存・送信・共有しません。具体的には:

  • 外部送信なし。本拡張が行う通信は、Amazon.co.jp のレビュー一覧ページの読み込みだけです。Amazon にログインしているときに、お使いのブラウザのログイン状態のまま読み込みます（商品ページを開くたびに最大6回。読み込む量を「多め」にすると最大11回。パネルで続きを読み込んだときはそのつど1回、CSV に書き出すときは新しい順・低評価それぞれ一覧の最後（100件）まで）。ログインしていないことがページから分かるときは、レビュー一覧を読み込みません（分からないときも、サインイン画面が返った時点で止めます）。読み込んだレビューは端末内で診断に使うだけで、外部へ送信しません。評価分布の計算も、レビュー文のAI解析も、すべてお使いの端末内（ブラウザ内）で完結します。
  • 分析・トラッキングなし。解析SDK・テレメトリ・第三者サービスを一切使用しません。
  • アカウント不要。サインインや登録は必要ありません。
  • レビューや診断結果を拡張の中に保存しません。読み取った評価分布やレビュー文、診断結果はメモリ上で処理されるのみで、本拡張が自動でディスクやクラウドに書き出すことはありません。例外として、あなたがパネルの「CSV で書き出す」を押したときだけ、読み込み済みのレビュー（日付・評価・タイトル・本文など。投稿者名は含みません）を CSV ファイルとしてお使いの端末に保存します。このファイルは端末内で作られ、どこにも送信されません。本拡張が保存するのは、レビューを取り込むタイミング（自動／パネルを開いたとき）と読み込む量（標準／多め）の設定だけで、ブラウザの拡張機能用の保存領域に置かれます。

端末内AIについて

対応端末では、Chrome 版は Chrome の組み込みAI（Prompt API / Gemini Nano）、Safari 版は Apple Intelligence（Foundation Models）を用いてレビュー文を解析します。この処理は完全に端末内で実行され、レビュー内容が外部に送信されることはありません。AIモデルのダウンロードはブラウザや OS の機能によるものであり、本拡張がデータを送信するわけではありません。

権限

本拡張が要求するブラウザ権限は、Chrome 版は storage だけ、Safari 版は storage と nativeMessaging です。storage は、レビューを取り込むタイミングと読み込む量の設定を保存するためだけに使います。nativeMessaging は、端末内AI（Apple Intelligence）が使えるかの確認と、解析するレビューの抜粋を、拡張から同じアプリの中の処理へ渡すためだけに使います。このやり取りは Mac の中だけで完結し、外部には送信しません。host_permissions は要求しません。Amazon.co.jp のページ上で動作し、読み取る対象は商品ページの評価分布・レビューと、同じサイトのレビュー一覧ページのみです。

お子様のプライバシー

サクラ診断は、お子様を含むいかなる利用者からもデータを収集しません。
