できること

商品ページのまま、レビューの偏りを見抜く。

評価（★）の近くに A〜F のバッジを出すだけ。バッジを押すと、判定の理由や評価分布、取り込んだレビューの一覧をその場で確かめられます。別のサイトを開く必要はありません。

A自然な分布で、目立った偏りなし
C二極化や集中投稿など、気になる兆候あり
F★5への極端な集中など、強い不自然さ
ログイン中

集中投稿・購入確認なし・不自然な日本語を検出

Amazon にログインしていれば、新しい順のレビューを読み込んで深掘りします。見つかった兆候は、評価分布と合わせてグレードに反映します。

  • 短期間に集中した高評価週ごとの投稿タイムラインでも確認できます
  • 「Amazonで購入」の付かない★5の多さ
  • 中国語簡体字が混じる高評価
  • 取り込むタイミングと読み込む量を選べます「自動」か「パネルを開いたとき」、「標準（50件）」か「多め（100件）」

レビュー タブ

気になるレビューを、商品ページのまま確認

取り込んだレビューを、低評価・集中期間・購入確認なし・簡体字で絞り込んで読めます。一覧の下までスクロールすると、続きもその場で読み込めます。

  • 「CSV で書き出す」で表にして保存新しい順と低評価のレビューを、それぞれ最大100件
  • 日付・★・タイトル・本文などの列で、Excel などで自由に分析できます
  • 投稿者名は書き出しません

対応端末

端末内AIが、文面の不自然さと低評価の要点をまとめる

パネルを開くと、端末内のAIがレビュー本文を解析し、サクラ度・不自然な点・低評価の要点を表示します。結果はグレードに混ぜず、別の観点として示します。

  • Chrome: 組み込みAI（Gemini Nano）モデル（約2GB）が未ダウンロードなら、パネルのボタンから準備できます
  • Mac: Apple IntelligencemacOS 26 以降で Apple Intelligence をオンにしている場合
  • AIに対応していない端末でも、A〜F の診断はそのまま使えます

🪶

邪魔をしない

評価（★）の近くに小さなバッジを置くだけ。クリックで詳細パネルが開きます。普段の買い物の動線を崩しません。

🔗

外部サイトに誘導しない

診断も、レビューを読むのも商品ページの中で完結。広告やアフィリエイトリンクはなく、リンクは amazon.co.jp の中だけです。

🗾

日本語のサクラに最適化

機械翻訳調・定型的な称賛・絵文字の多用・酷似した言い回し、簡体字の混入など、日本語レビュー特有のシグナルを見ます。

🐢

Amazon に負担をかけない

レビュー一覧は間隔を空けて順番に読み込み、確認画面が出たらすぐに止めます。ログインしていないと分かるときは読み込みません。

🧭

Chrome と Mac の Safari に

どちらでも、診断・レビューの一覧・CSV の書き出しが使えます。端末内AIは、Chrome は Gemini Nano、Mac は Apple Intelligence を使います。

⚖️

断定しない

表示するのは「参考情報」。サクラの有無を断定するものではありません。最終判断はあなた自身で。

プライバシー

データは端末の外に出ません。

サクラ診断の通信は、Amazon.co.jp のレビュー一覧ページを読み込むことだけ。レビューの内容も診断結果も、どこにも送信されず、拡張の中に保存もされません（保存するのは取り込みタイミングと読み込む量の設定だけ。レビューは、あなたが CSV に書き出したときだけ、あなたの端末にファイルとして保存されます）。アカウント登録もトラッキングもありません。

0 外部送信 0 トラッカー 0 拡張内でのレビュー保存 要求する権限：storage

Safari 版は、Mac の端末内AI（Apple Intelligence）とやり取りするために nativeMessaging も使います。このやり取りは Mac の中だけで完結します。

いつものブラウザに、無料で。

Chrome 版と Safari（Mac）版の機能は同じです。端末内AIの仕組みだけが異なります。

Chrome

パソコン版の Chrome に追加します。端末内AIは、Chrome の組み込みAIに対応した端末で使えます。

無料Chrome ウェブストア

Safari（Mac）

App Store からアプリを入れて起動し、Safari の設定の「機能拡張」で「サクラ診断」をオンにします。端末内AIは、Apple Intelligence に対応した Mac（macOS 26 以降）で使えます。

無料Mac App Store
